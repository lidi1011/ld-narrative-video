# 视觉与声音配置

本参考规定跨镜头的配置关系。它不替项目的 `contracts-and-qc.md` 定义 JSON schema，也不把某种风格、布局或引擎变成某个表现模块的前提。

## 视觉配置的分层

将以下内容写入项目的 `DESIGN.md` 或其明确引用的配置，并让所有镜头读取同一份配置：

- **风格**：颜色、字体、线条、圆角、材质、阴影、图标和动效气质；
- **布局**：所选画幅的画布尺寸、帧率、内容安全区、边距、信息密度和字幕位置；
- **引擎**：当前使用的 HyperFrames 工程、组件和原生命令；
- **声音**：旁白、素材原声、字幕、BGM 和 SFX 的选择及混音约束。

风格不决定布局，布局不决定引擎；更换其中一层时记录实际影响。颜色、字体和动画值保持参数化，使图解、录屏、实拍、文字、IP 和真人镜头能共用视觉语言。

支持 16:9（1280×720，默认）与 9:16（720×1280）。竖屏将步骤与对比改为纵向阅读，媒体在上、说明在下，字幕靠下但预留边距。新建任务时用 `--aspect-ratio 9:16`。已有横屏改竖屏须新建任务、迁入原文和素材并重新检查；不要只改旧项目尺寸或裁切旧成片。

## 文字与字幕

文字是信息层，不等同于旁白的逐字堆叠。保留定稿用词、产品名、数字和英文名词；允许按安全区换行和分行，不通过字幕改写事实或遮盖实际发音差异。

每个文字层都要检查：

- 在当前画幅的安全区内完整显示，没有溢出、遮挡或被 UI/素材边缘切掉；
- 字号、字重、行距和停留时长足以在实际播放尺寸读取；
- 前景与背景对比度稳定，素材变化后仍可读；
- 强调层有清楚的层级，避免所有词同时跳动或和关键操作重叠；
- 中英文、数字和标点的换行符合内容意图，不产生歧义。

字幕事件使用同一成片时间坐标。语音对齐的实际起止、静音间隙和字幕允许的视觉延长分开记录；相邻镜头共用边界，渲染时由统一规则映射到帧，避免独立取整造成漏帧或重叠。

## 动效与布局变化

动效必须让观众看见信息如何出现、比较、归组、聚焦、触发或收束。对于每个变化，说明起始状态、发生时点、结束状态和触发依据。静态素材只能做其实际支持的移动、缩放或裁切；它不能凭空产生未提供的动作、操作结果或物理变化。

A-roll/B-roll 可以作为主讲与补充画面的编辑标记，但不规定颜色、背景、角色或图解类型。纯信息图可以完整承担全片；录屏、实拍、IP、真人和文字可以自由组合，只要镜头职责和信息变化可读。

## 声音分支

按用户选择使用下列一种或多种来源：

1. **已有配音**：保留原始文件和内容版本，以它作为时间依据。
2. **整篇 TTS**：默认由音频 Agent 适配豆包，以定稿文本为一次合成的内容依据。连接信息、服务配置、音色和缓存由音频 Agent 按用户明确授权读取；通用技能不硬编码路径、密钥或其他项目的接口适配器。
3. **素材原声**：登记原媒体时间段、剪切和成片映射；补充画面围绕实际声音编排。
4. **无声**：不生成 TTS、占位音轨或无来源音乐，使用阅读节奏和信息事件驱动镜头。

有语音时，先保存原始返回音频，分析需要的 WAV 另行生成；声道或采样率转换只是格式处理，不宣称为音质提升。发送前检查当前豆包接口实际限额，超过限额时在合成前处理，不以逐句拼接冒充整篇合成。ASR 可以提供初步识别和时间线索，文字差异需要重对齐或修正，不能只换字幕。

BGM 和 SFX 只有在用户选择或项目已有配置时加入。音乐不能盖住人声，转场不能截断尾音；保留原声的录屏或真人镜头不能被默认替换。无声任务不因模板存在而强行添加声音。

## 视觉与声音检查

成片检查至少覆盖画幅安全区、中文可读性、对比度、素材版本、时间边界和解码结果。有声视频还要完整听查，重点听转场、结尾、静音间隙、突兀拼接、尾音截断、爆音和背景声遮盖。检查结论只写已实际执行的项目；产品操作、数据和结果需要对应真实素材或明确的示意标记。
