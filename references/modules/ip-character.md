# `ip-character` IP 角色模块

IP 角色是可选的表现分支。只有当前任务明确启用角色、或分镜确实需要主持/情境角色时加载；没有角色需求时不索要参考图、不制作三视图，也不因缺少角色资产阻塞纯图解、录屏或素材视频。

## 输入与准备

至少登记角色资产、身份特征、允许使用的姿势/表情、场景参考、来源与版本，以及它在本镜头承担的叙事职责。把不同参考分别标注用途：身份参考用于保持人物特征，风格参考用于笔触、材质和色彩，场景参考用于环境与构图；不要用风格图替代身份依据。

角色线条、配色、比例和阴影应服从全片 `DESIGN.md`。只为当前真实镜头准备需要的姿势、表情、道具或分层素材，优先复用已检查资产；新资产写明镜头用途和来源。角色形象由当前任务提供或明确选定，不预设默认人物。

## 实现提示

角色可承担主持、情境主角、反应、第一人称或转场锚点，也可以只出现一个镜头。不要为了满足 A/B 比例而固定角色出场或每隔几秒切换；A/B 仍只是编辑标记。角色应与信息图、录屏和文字共享布局与声音规则，而不是带来一套独立视觉系统。

平面人物图只支持它真实具备的移动、缩放、裁切、镜头运动或有限层级动画。换表情、转身、操作道具、走路或与画面产生复杂交互，需要对应姿势/表情图、分层资产或专门视频片段；不能从一张正面图推断这些动作已经发生。缺少动作资产时改写为镜头运动、替换素材或示意表达，并在分镜中说明。

## 质量检查

- 不同镜头的身份特征、头身比、服装、发型、标志细节和视角一致；
- 身份参考与风格参考的职责没有混用，角色没有因风格变化失去辨识度；
- 角色动作只使用已提供或实际生成并核验的资产；
- 手、道具、遮挡、边缘和透明层在所选画幅合成后没有明显错误；
- 角色没有遮挡文字、录屏控件、图表关系或关键证据；
- 角色镜头的声音、字幕和事件仍与全片同一时间轴一致。

角色模块只负责角色资产和有限动作的编排，不负责替全片选择样式、布局、引擎或声音，也不把角色成功出现当作通用技能完成的证据。
