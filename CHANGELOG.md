# Changelog

## 0.2.0-rc.1 — 2026-09-15

- Cross-platform Node/Python launchers; explicit UTF-8 and portable subprocess arguments.
- Bundled Noto Chinese font with OFL and source hash; font assets included in build fingerprints.
- Local doctor probes dependencies, workspace, loopback, browser and loaded font without cloud calls.
- Environment-variable TTS example works across OS families; Windows file-mode check fails with an actionable alternative.
- Agent-neutral installation and capability fallback instructions; portable unit tests.
- Existing task copies are not automatically upgraded.
